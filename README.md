# 🐍 Snake Water Gun Game – Advanced GUI (Python)

A **modern GUI-based Snake–Water–Gun game** built using **Python and Tkinter**.
This project enhances the classic console game with a **graphical interface, dark/light mode, scoreboard, sound effects, and reset functionality**.

---

## 🚀 Features

* 🎮 Button-based gameplay (no typing required)
* 🌙 Dark / ☀️ Light mode toggle
* 📊 Live score tracking
* 🔄 Reset / Play again option
* 🔊 Sound effects for win, lose & draw
* 🖥️ Clean and modern Tkinter UI
* 🧠 Computer makes random moves

---

## 🕹️ Game Rules

* **Snake 🐍 beats Water 💧**
* **Water 💧 beats Gun 🔫**
* **Gun 🔫 beats Snake 🐍**
* Same choice → Draw

---

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter (GUI)**
* **Random module**
* **Winsound** (for sound effects on Windows)

> ⚠️ Sound effects work on **Windows OS** only.
> For Linux/Mac, sound support can be added using other libraries.

## 🎮 How to Play

1. Click **Snake**, **Water**, or **Gun**
2. The computer chooses randomly
3. Result is displayed instantly
4. Score updates automatically
5. Use:

   * 🌙 Dark / ☀️ Light button to switch theme
   * 🔄 Reset button to restart the game
